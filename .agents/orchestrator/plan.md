# Orchestrator Plan: ESP32-S3 Diagnostics & Telemetry Build

## Objective
Orchestrate specialist subagents to generate technical blueprints and a master Claude Code prompt for an ESP32-S3 Diagnostic Web Server firmware build. This firmware enables rapid hardware validation via a Wi-Fi Access Point (AP) web server streaming real-time IR sensor telemetry and accepting low-latency manual motor commands.

## Hardware & System Context (from Config.h)
- **Microcontroller**: ESP32-S3 (Wi-Fi AP mode)
- **IR Array**: 10x TCRT5000 sensors on GPIOs 1, 2, 4, 5, 6, 7, 15, 16, 17, 18
- **Motor Driver**: L298N controlling Left (IN1: 12, IN2: 13, ENA: 11) and Right (IN3: 14, IN4: 21, ENB: 47) motors with 20kHz 8-bit LEDC PWM
- **I2C / Display / Other**: MPU6050 (0x68), SSD1306 OLED (0x3C) on SDA 38 / SCL 39

## Work Breakdown Structure (Milestones)
- **Milestone 1**: Generate Technical Blueprints under `Self_Test_Diagnostics/knowledge/`:
  - `web_server_architecture.md`: ESP32-S3 AP setup, async web server, WebSockets/SSE protocol, event loop.
  - `motor_control.md`: Directional pin mappings, PWM configuration, motor safety timeouts.
  - `telemetry.md`: 10x IR array sampling, bitmask encoding, streaming payload structure.
  - `ui_dashboard_layout.md`: HTML/JS UI dashboard wireframe, components, interactive controls.
- **Milestone 2**: Draft Finalized Master Prompt under `Self_Test_Diagnostics/prompts/Claude_Diagnostics_Prompt.md`:
  - Comprehensive instruction set for Claude Code to generate standalone diagnostic firmware.
- **Milestone 3**: Review & Verification:
  - Independent review of deliverables for technical precision, completeness, and file type compliance.

## Execution Strategy
- Worker subagent (`teamwork_preview_worker`) dispatched for M1 and M2.
- Reviewer subagent (`teamwork_preview_reviewer`) dispatched for M3.
- STRICT CONSTRAINT: Absolutely zero `.ino`, `.cpp`, `.h`, or `.py` code files generated by agents. Only `.md` deliverables.
